# Smart Internship Finder

## Project Description

Smart Internship Finder helps students discover internships based on their skills and identifies missing skills required for better opportunities.

## Features

- Internship Recommendation
- Skill Matching
- Match Percentage
- Skill Gap Analysis
- Responsive Design

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download all files.
2. Keep them in the same folder.
3. Open index.html in any browser.
4. Enter skills.
5. Click Find Internships.

## Example Input

Python, SQL
